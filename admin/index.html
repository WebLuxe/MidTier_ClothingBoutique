Repository settings

How do I get a token?
  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Name it "Shop admin" and pick an expiry date.
  3. Under Repository access choose Only select repositories → your shop's repository.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Generate, copy the token and paste it above. Keep it private: anyone with it can edit the site.
